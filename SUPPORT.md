# Support — Value Coach for Cursor

Thanks for using Value Coach. This is a free, independently maintained extension.

## Getting help

1. Check [README.md](README.md) for install, settings, and privacy kill switches.
2. Check [PRIVACY.md](PRIVACY.md) for what the extension accesses.
3. Use the editor command palette:
   - **Value Coach: Open Panel**
   - **Value Coach: Refresh Now**
   - **Value Coach: Clear Local Data**
   - **Value Coach: Usage Menu**

## Report a problem

Please include:

- Extension version (from the Extensions view)
- OS (Windows / macOS / Linux)
- Whether `valueCoach.showUsage` and `valueCoach.readTranscripts` are on
- What you expected vs what happened (screenshots of the status bar help)

**Do not** paste Cursor session tokens, password manager exports, or full transcript files into issues.

Preferred channels (use whichever is live for your install source):

- [GitHub Issues](https://github.com/sharondev-cell/cursor-value-coach/issues)
- Marketplace / Open VSX **Q&A** on the listing

## Security / privacy incidents

If you believe Value Coach has a security or privacy issue, contact the publisher through the listing Q&A with subject **Security** and avoid sharing secrets in public threads. For Cursor Marketplace publishers, security incidents affecting plugin data may also need notice to Anysphere as required by their publisher terms.

## What we don’t support

- Cursor account billing disputes (use Cursor’s own Plan & Usage / support)
- Guaranteeing that live usage % works on every OS (decrypt is implemented for Windows today; other OSes get Plan & Usage deep-link)
- Guaranteeing Cursor internal APIs never change

## Affiliation

Value Coach for Cursor is **not** affiliated with Anysphere, Inc. or Cursor. “Cursor” is used only to describe compatibility.
